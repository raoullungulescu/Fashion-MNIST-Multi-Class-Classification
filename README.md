# Fashion MNIST Classification 

Classification of clothing images (10 classes) from Fashion MNIST, provided as 784-feature vectors obtained through random projection. Includes statistical analysis, PCA, and model comparison.

## Results

| Model | Accuracy (5-fold CV) |
|---|---|
| KNN | 83.39% |
| Logistic Regression | 84.87% |
| Random Forest | 85.67% |
| **SVM (RBF, C=10, gamma=0.01)** | **89.47%** |
